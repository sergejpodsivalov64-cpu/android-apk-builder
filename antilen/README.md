# Антилень — Android MVP

Первая версия: локальные задания, денежные награды, опыт героя, предложения квестов и список целей. Данные сохраняются на телефоне.

**Ограничения:** сложность пока выбирается вручную; герой пока текстовый прототип; сумма реально отложенных денег общая, не распределяется между целями. Это не готовая финальная версия.

Сборка: Android Gradle Plugin 8.7.3, JDK 17, `gradle assembleDebug` из каталога `antilen`. APK: `antilen/app/build/outputs/apk/debug/app-debug.apk`.
